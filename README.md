# Roteamento-REACT

Exercício de roteamento em React e TypeScript para praticar navegação entre páginas.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Interface em `vite-project/src/App.tsx`.

**Tecnologias:** `CSS`, `HTML`, `React`, `TypeScript`, `Vite`.

## Executar localmente

```bash
cd vite-project
npm install
npm run dev
```
